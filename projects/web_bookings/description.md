# Pet grooming bookings (web)

A booking site for a one-location dog grooming shop.

- Staff publish appointment slots (a start time; every slot is 60 minutes).
- Customers see open slots for a day and book one for a named pet. A slot holds one booking.
  Customers can cancel their own bookings up to 24 hours before the start.
- A slot picker shows the open slots for a day as buttons with the local time (America/Los_Angeles).
